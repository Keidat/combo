## GitHub Pages

폴더 내용물을 저장소 최상위에 업로드하고 Settings → Pages → Deploy from a branch → main / (root)로 설정하세요. index.html이 최상위에 있어야 합니다. 설치·빌드·백엔드는 필요 없습니다.

## 범위·사용법

- 각 퀴즈의 Docs 근거 원문 확인에서 출처와 근거 문장을 확인할 수 있습니다.
- notes.md는 Docs 기준 정리, 변경내역.md는 제외·교체 내역입니다.
- standalone.html은 단일 파일 버전입니다.
- 가상 터미널은 실제 명령을 실행하지 않습니다.
- 진도는 기기·브라우저별로 저장됩니다. 문제 변경 때문에 이전 버전 기록과 분리한 새 저장 키를 사용합니다. 옛 기록은 삭제하지 않습니다.
- 동등한 옵션 배치와 입력 공백은 일부 허용하지만 원문에 없는 새 명령을 요구하지 않습니다.
- 문법·채점·출처·패키지 검증을 진행했습니다. 화면 조작 검증은 브라우저 보안 정책으로 수행하지 못했습니다.
